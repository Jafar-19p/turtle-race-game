# Turtle Race Game

A classic interactive Turtle Race game built with Python. Place your bet on a turtle, watch them race across the screen with randomized speeds, and find out if you win!

## Features

- **Interactive Betting:** Enter your color choice (Red, Blue, or Yellow) via a graphical prompt box before the race starts.
- **Randomized Movement:** Turtles move forward at dynamic random speeds during each step of the race.
- **Dynamic Winner Detection:** Automatically tracks which turtle crosses the finish line first and extracts its color attribute to evaluate the bet.
- **Visual Feedback:** Changes background color and displays the final Win/Lose message dynamically.

## Built With

- **Python** (Programming Language)
- **Turtle Graphics** (Built-in GUI Library)
- **Random Module** (For generating dynamic speeds)
